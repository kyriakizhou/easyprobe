HUMAN: How do I set up proper SSL/TLS for my web application?

A: Essential for production: HTTPS everywhere. Get certificate from Let's Encrypt (free), paid CA, or your cloud provider. Terminate TLS at load balancer (AWS ALB, Cloudflare, nginx) rather than at your application for simplicity. Configure strong cipher suites.

H: Should I terminate TLS at the load balancer or application?

A: Load balancer (AWS ALB, Cloudflare) is typically easier - managed certificate renewal, optimized TLS handling. Internal traffic is then HTTP. If you need end-to-end encryption (compliance requirements), terminate at application but that adds complexity.

H: How do I get and manage certificates?

A: Let's Encrypt: free certificates, auto-renewal with certbot or built-in cloud integrations. AWS ACM: free for AWS resources, auto-renewal. Paid CAs for EV certificates if you need the green bar. Always set up auto-renewal - expired certs cause outages.

H: What about HSTS? Should I enable it?

A: HSTS (HTTP Strict Transport Security) tells browsers to only use HTTPS. Add header: Strict-Transport-Security: max-age=31536000; includeSubDomains. Include preload for maximum protection. But be careful - once enabled with long max-age, you can't easily undo without waiting out the duration.

H: How do I redirect HTTP to HTTPS?

A: At your load balancer or reverse proxy. Return 301 redirect from HTTP to HTTPS equivalent URL. Be careful with POST requests - 301 redirect loses the body. Consider HSTS instead of relying purely on redirects. Eventually HTTP requests should be rare.

H: What's the SSL Labs rating I should aim for?

A: A or A+ on SSL Labs test. Avoid old protocols (TLS 1.0, 1.1). Use TLS 1.2/1.3 only. Strong cipher suites prioritizing ECDHE. Enable HSTS for A+. Most modern configurations get A easily. Run the test periodically to catch degradation.
