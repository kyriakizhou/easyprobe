HUMAN: What's a file format? Why are there different ones?

A: A file format is the way data is organized and stored in a file. Different formats exist because different types of content need different handling. A photo needs to store color information for millions of pixels, while a text document just needs letters and formatting. The file extension (.jpg, .pdf, .doc) tells your computer what kind of file it is.

H: Why can't I open some files?

A: You need the right software to open specific file formats. A .docx file needs Word or a compatible app. A .psd file needs Photoshop. If you don't have the right program, your computer doesn't know how to interpret the data. Sometimes you can find free alternatives that open the same format.

H: What's the difference between .jpg and .png?

A: Both are image formats but with different strengths. JPG compresses photos efficiently but loses some quality. PNG preserves quality perfectly and supports transparency (see-through backgrounds) but creates larger files. JPG is great for photos; PNG is better for graphics and logos.

H: Why do documents come in .pdf format?

A: PDF stands for Portable Document Format. It keeps documents looking exactly the same on any device - the fonts, layout, and formatting won't change. That's why official forms, contracts, and ebooks often use PDF. It's like a digital printout.

H: How do I change a file's format?

A: Usually you open the file in an appropriate program and save or export it as a different format. For example, open an image in a photo app and "Save As" a different type. For documents, you might print to PDF. There are also free online converters for many formats.

H: Does the format affect file size?

A: Yes, significantly! Different formats compress data differently. A song as WAV might be 50MB, but as MP3 it might be 5MB. Some formats prioritize quality, others prioritize small file size. The same content can be very different sizes in different formats.
