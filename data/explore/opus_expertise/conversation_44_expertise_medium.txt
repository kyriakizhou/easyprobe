HUMAN: I need to implement audit logging in our application. What events should I log and how?

A: Audit logs serve compliance and debugging. Essential events: authentication (login, logout, failed attempts), authorization (permission changes, access denials), data changes (CRUD on sensitive entities), and administrative actions. Format should be structured, immutable, and include who/what/when/where.

H: What fields should each audit log entry have?

A: Core fields: timestamp, actor (user ID or system), action type, resource type and ID, old/new values for changes, IP address, user agent, request ID for correlation. Consider: session ID, organization/tenant ID for multi-tenant apps, and result (success/failure with reason).

H: Where should I store audit logs? Same database as application data?

A: Separate storage is recommended. Audit logs should be append-only and tamper-evident. Options: dedicated database table with append-only permissions, specialized log stores (CloudWatch Logs, ELK), or compliance-focused services. Keep them longer than application data - years for compliance.

H: How do I make them tamper-proof?

A: Make the database append-only - application user can INSERT but not UPDATE/DELETE. Regular backup to immutable storage (S3 with object lock). Hash chains linking entries (each entry includes hash of previous) detect tampering. For high compliance, consider third-party audit solutions.

H: This seems like it could affect performance. Every action creates a log.

A: Use async writes. Queue audit events and write them in batches. The audit log write shouldn't slow down user actions. If the queue fails, have a fallback - don't block operations, but do alert. For reads, index appropriately and archive old logs.

H: What about GDPR? We need to delete user data on request.

A: Tension between audit immutability and data deletion. Options: pseudonymize user references (replace user ID with hash), exclude directly identifying info from audit logs, or document audit logs as legitimate interest exemption with appropriate retention. Consult your legal/compliance team.
