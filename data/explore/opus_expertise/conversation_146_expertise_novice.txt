HUMAN: What's a software bug? I hear about updates fixing bugs.

A: A bug is an error, flaw, or unintended behavior in software. The name comes from early computing when an actual moth caused problems in a computer! Today it means anything that makes software behave incorrectly - crashes, freezes, features not working right, or unexpected results.

H: How do bugs get into software?

A: Programmers are human and make mistakes. Software is incredibly complex - millions of lines of code interacting in ways that are hard to predict. Bugs slip through despite testing. Sometimes features work fine individually but cause problems together. It's nearly impossible to catch everything.

H: What's the difference between a bug and a crash?

A: A crash is one type of bug - it's when software stops working completely and closes unexpectedly. Bugs can be subtler: a button that doesn't respond, text that displays incorrectly, or a feature that only fails in certain situations. Crashes are just the most dramatic bugs.

H: Why do updates say they fix bugs?

A: Developers continuously find and fix bugs after software is released. When they release updates, they bundle bug fixes together. Sometimes they also add new features or improve performance. That's why keeping software updated is important - you get the fixes.

H: Should I report bugs I find?

A: If you can! Most companies have feedback options or support channels where you can describe problems. Good bug reports include what you did, what happened, and what you expected. Developers often can't fix bugs they don't know about.

H: Why do some bugs never get fixed?

A: Some bugs are very hard to reproduce or fix without breaking other things. Companies prioritize - severe bugs get fixed quickly, minor annoyances might wait. Sometimes software is so old that developers have moved on. Resources and priorities determine what gets fixed.
