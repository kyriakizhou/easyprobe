HUMAN: We're implementing a custom consensus protocol for our distributed key-value store. What are the key considerations beyond basic Raft?

A: Beyond basic Raft: linearizable reads (how to serve reads without leader roundtrip), membership changes (joint consensus or single-server changes), snapshotting and log compaction, pipelining for throughput, and pre-vote to prevent disruption from partitioned nodes.

H: Let's focus on reads. We want strong consistency but leader roundtrip adds latency.

A: Options for linearizable reads: leader lease (leader knows it's leader for duration, serves reads locally), read index (leader confirms leadership, then serves read - avoids write log), or quorum reads (read from majority, use highest committed value).

H: How does leader lease work exactly?

A: Leader gets lease for duration T when it receives heartbeat acknowledgments. During lease, it's safe to serve reads because no other leader can be elected. Relies on clock bounds - if clocks drift too much, safety is violated. Requires bounded clock skew assumption.

H: That clock dependency seems risky.

A: It is. Some systems avoid it: read index requires leader to prove leadership with a quorum read before serving. Or use quorum reads - read from majority of replicas, get value with highest term/index. Slower but no clock dependency. Trade-off between latency and assumptions.

H: What about write throughput? Basic Raft is limited by leader.

A: Batching: leader batches multiple writes into single consensus round. Pipelining: don't wait for round N to complete before starting N+1. Multi-Paxos / parallel commits for independent keys. Partitioning: separate Raft groups for different key ranges (like CockroachDB ranges).

H: How do we handle partitioned nodes that still think they're leader?

A: Pre-vote extension: before election, candidate asks if it would win. If it can't reach a quorum, it doesn't start election. Prevents partitioned old leaders from incrementing term and disrupting the cluster when they rejoin. CheckQuorum: leader steps down if it can't reach majority.
