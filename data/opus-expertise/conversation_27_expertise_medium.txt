HUMAN: I'm setting up monitoring and alerting for our production systems. What metrics should I focus on?

A: Start with the "Four Golden Signals" from Google SRE: latency (response times), traffic (requests per second), errors (error rate percentage), and saturation (resource utilization). These give you comprehensive system health visibility. Add business metrics relevant to your domain.

H: We're running a Node.js API with PostgreSQL. What specific metrics for these?

A: For Node.js: event loop lag, memory heap usage, active handles, garbage collection time, request duration percentiles. For PostgreSQL: active connections, connection pool utilization, query duration percentiles, cache hit ratio, dead tuples (need vacuum), replication lag if applicable.

H: What threshold should trigger alerts?

A: Avoid alerting on every anomaly - alert fatigue is real. Alert on user-impacting issues: error rate above threshold (e.g., 1% for 5 minutes), p99 latency above SLA, service completely unreachable. Resource warnings (disk 80% full) can be lower urgency. Match severity to required response time.

H: Should I use Prometheus, Datadog, or something else?

A: Prometheus is excellent for self-hosted, powerful query language, open-source ecosystem with Grafana dashboards. Datadog is great SaaS with good integrations but expensive at scale. CloudWatch works if you're all-AWS. Consider what you can maintain - SaaS reduces ops burden.

H: How do I avoid getting paged for things that fix themselves?

A: Alert on symptoms, not causes. Alert if errors persist for several minutes, not on a single error. Use multi-window alerting - short window catches acute issues, long window catches slow burns. Have burn rate alerts for gradual degradation. Tune thresholds based on actual incidents.

H: What about on-call structure?

A: Start with a rotation - different person each week. Define escalation paths and response time expectations. Have runbooks for common alerts. Post-incident reviews improve both alerts and responses over time. Tools like PagerDuty or Opsgenie manage scheduling and escalation.
